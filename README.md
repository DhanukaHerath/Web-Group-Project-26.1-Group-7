# Web-Group-Project-26.1-Group-7    -    NSBM ArtCraft — University Art & Literary Showcase System
A modern web platform for NSBM students to showcase visual artworks (paintings, sketches, photography, handcrafts) and literary works (poems, short stories), with community interactions and university exhibition registrations.
Key Features (Grouped by Role)

Bullet points showing what users can actually do. Grouping them by Student and Admin makes it very clear and professional:

Student Features:
Browse the interactive 14-column kinetic gallery wall and ambient video streams.
Upload visual artworks or submit literary works with automatic word-count calculation.
Like, rate (1–5 stars), comment, and follow favorite creators.
Register for university showcase exhibitions.
View personal submission history and approval status.
Administrator Features:
Secure admin dashboard with moderation review queue (approve/reject submissions).
Create and manage exhibition events.
View platform analytics (total students, active works, category distributions).
Immutable admin audit log.
